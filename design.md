# ThatGuyCodes Design System Specification (Obsidian & Daylight)

## 1. Brand & Style

### 1.1 Dual-Persona Foundation: Circadian Engineering Ergonomics
`thatguycodes` bridges the architectural precision of an industrial developer cockpit with the high-converting velocity of a modern digital commerce and knowledge platform. It embodies the ethos of **The Sovereign AI & $0/mo Full-Stack Engineer**: production-grade capabilities, absolute cost sovereignty, zero corporate bloat, tactile keyboard ergonomics, and total transparency.

The design system operates with first-class support for two synchronized visual protocols:

1. **Obsidian Dark Mode ("The Sovereign Engineering Cockpit - Precision in Darkness"):**
   - Deep zinc-black backgrounds (`#09090b`, `#0c0c0f`, `#121215`, `#18181b`) engineered to eliminate glare, reduce OLED power draw, and minimize eye strain during nocturnal homelab orchestration and deep architectural code dissection.
   - Electric Lavender / Soft Violet (`#a78bfa`) signal precision.
   - Hairline zinc boundary strokes (`#27272a`, `#52525b`) replacing heavy drop shadows.

2. **Daylight Mode / Daylight Protocol ("The Sovereign Daylight Cockpit - Pristine Architectural Clarity"):**
   - Fresh, glare-free daylight canvas with an ultra-subtle lavender tint (`#FAF8FF`) and pure white card surfaces (`#FFFFFF`).
   - Deep Royal Violet (`#6D28D9` / Purple 700) primary accent delivering an uncompromising **WCAG AAA 7.5:1 contrast ratio** against white surfaces.
   - Soft elevated backgrounds (`#F4F2FA`) and crisp lavender-slate boundary strokes (`#E2DEF0`, `#ECE7F6`) ensuring structural clarity under high ambient light conditions, technical presentations, and daytime review sessions.

### 1.2 Emotional Target
- **Mastery, Autonomy & Calm Authority:** Developers, founders, and indie hackers immediately sense that every piece of software on the site is an uncompromised proof-of-work that can be self-hosted, audited, and deployed without paying recurring SaaS taxes.
- **High-Density Cognitive Clarity:** Dense technical architecture diagrams, multi-file code diffs, interactive Sandpack sandboxes, and agentic execution streams render with instant legibility and disciplined typographic cadence across both dark and light ambient conditions.

## 3. Typography

### 3.1 Font Family Hierarchy
The typographic system standardizes on **Geist** across all interface levels for a unified, modern, and disciplined cadence:
- **Headlines & Display:** `Geist`, sans-serif (Tight letter-spacing `-0.02em` to `-0.03em`, heavy structural posture).
- **Body & Prose:** `Geist`, -apple-system, BlinkMacSystemFont, sans-serif (Balanced tracking, distortion-free across long-form MDX technical deep-dives).
- **Monospace, Telemetry & Code:** `Geist Mono` (with `JetBrains Mono` and `ui-monospace` fallback) for code blocks, terminal buffers, tabular metrics, and inline chips.

## 4. Layout & Spacing

### 4.1 High-Density Engineering Grid
- **Maximum Content Width:** `1280px` (`max-w-7xl`) for dashboards & store views; `768px` (`max-w-3xl`) for MDX prose to preserve optimal 65–75 character line lengths.
- **Base Grid:** `4px` / `8px` strict spatial rhythm (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 12px, `space-lg` = 16px, `space-xl` = 24px, `space-2xl` = 32px).
- **Desktop Workbench (1280px+):** Sticky 240px technical navigation rail, fluid canvas/prose workspace, and optional 320px contextual telemetry/TOC sidebar.
- **Tablet (768px - 1024px):** Collapsed navigation rail to icon rail (64px) with off-canvas slideover drawers for TOC and AI chat.
- **Mobile (<768px):** Single-column stacked flow with fixed bottom action trigger bar (`h-14`) for quick access to `Cmd+K`, TOC, and Store checkout.

## 5. Elevation & Depth

### 5.1 Obsidian Dark Elevation
Shadows are minimized in favor of crisp boundary borders and micro-luminance stepping:
- **Layer 0 (Canvas):** `#09090b` baseline background.
- **Layer 1 (Card / Container):** `#121215` / `#18181b` with `1px solid #27272a` and subtle top highlight.
- **Layer 2 (Elevated Popover / Dropdown):** `#18181b` with `1px solid #52525b` and tight ambient drop shadow `0 8px 24px -4px rgba(0, 0, 0, 0.7)`.
- **Layer 3 (Modal / Command Palette):** `#0c0c0f` with `1px solid #52525b`, focused accent border `#a78bfa`, and backdrop filter `backdrop-blur-md bg-black/80`.

### 5.2 Daylight Mode Elevation
Daylight utilizes clean structural containment combined with soft ambient light falloff:
- **Layer 0 (Canvas):** `#FAF8FF` airy lavender-white baseline background.
- **Layer 1 (Card / Container):** `#FFFFFF` with `1px solid #E2DEF0` and crisp micro-shadow `0 1px 3px 0 rgba(0, 0, 0, 0.05), 0 1px 2px -1px rgba(0, 0, 0, 0.05)`.
- **Layer 2 (Elevated Popover / Dropdown):** `#F4F2FA` or `#FFFFFF` with `1px solid #E2DEF0` and shadow `0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -2px rgba(0, 0, 0, 0.05)`.
- **Layer 3 (Modal / Command Palette):** `#FFFFFF` with `1px solid #E2DEF0`, focused border `#6D28D9`, diffuse ambient shadow `0 20px 25px -5px rgba(0, 0, 0, 0.08), 0 8px 10px -6px rgba(0, 0, 0, 0.04)`, and backdrop filter `backdrop-blur-md bg-slate-900/20`.

### 5.3 Focus Rings & Status Glows
- **Keyboard Focus Ring:**
  - *Obsidian:* `2px solid #a78bfa` with `2px offset` (`box-shadow: 0 0 0 2px #09090b, 0 0 0 4px #a78bfa`).
  - *Daylight:* `2px solid #6D28D9` with `2px offset` (`box-shadow: 0 0 0 2px #FFFFFF, 0 0 0 4px #6D28D9`).
- **Primary Violet Glow:**
  - *Obsidian:* `box-shadow: 0 0 20px -3px rgba(167, 139, 250, 0.45)`
  - *Daylight:* `box-shadow: 0 4px 14px 0 rgba(109, 40, 217, 0.20)`

## 8. Atomic Design System Hierarchy (Dark Mode & Daylight)

The design system is strictly organized following Brad Frost's **Atomic Design Methodology**, ensuring modular composability from primitive CSS tokens up to full GenUI page templates:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    ATOMIC DESIGN SYSTEM ARCHITECTURE                         │
├─────────────┬────────────────────────────────────────────────────────────────┤
│ Atomic Tier │ Components & Tokens in `thatguycodes`                          │
├─────────────┼────────────────────────────────────────────────────────────────┤
│ 1. Atoms    │ • Primitive Tokens: `--color-obsidian-*`, `--radius-*`, fonts   │
│             │ • UI Primitives: `<Button />`, `<Badge />`, `<Input />`        │
│             │ • Micro-Tokens: `<kbd>`, `<DotBeacon>`, `<HairlineSeparator>`   │
├─────────────┼────────────────────────────────────────────────────────────────┤
│ 2. Molecules│ • `<SearchInput />` (Input + Search Icon + `⌘K` Keycap)        │
│             │ • `<AccordionItem />` (Trigger + Title + Badge + Chevron)      │
│             │ • `<StatusBeacon />` (Ping Animation + Dot + Telemetry Text)   │
│             │ • `<DialCodeSelector />` (Country Code Dropdown + Flag + Input)│
├─────────────┼────────────────────────────────────────────────────────────────┤
│ 3. Organisms│ • `<AccordionGroup />` (Multi-item stateful drawer system)     │
│             │ • `<PhoneLoginCard />` (Phone selector + Submit + Security Tag)│
│             │ • `<CodeSandbox />` (Terminal dock + Tabs + Shiki + Runner)    │
│             │ • `<PolarCheckoutCard />` (Badge + Pricing + Features + CTA)   │
│             │ • `<ArchitectureExplorer />` (SVG canvas + Node graph + Zoom)  │
├─────────────┼────────────────────────────────────────────────────────────────┤
│ 4. Templates│ • `<ComponentWorkbenchLayout />` (Sidebar + Preview + Code)   │
│ & Pages     │ • `<MDXTechnicalArticleLayout />` (Prose + Scrollytelling)    │
│             │ • `<StorefrontProductGrid />` (Value Ladder + Polar Checkout) │
└─────────────┴────────────────────────────────────────────────────────────────┘
```
