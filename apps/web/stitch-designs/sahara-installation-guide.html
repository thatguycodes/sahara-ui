Installation & Quickstart

Equip your frontend with artisanal warm minimalist primitives. Designed to live directly inside your source repository with full ownership of every line of code.

schedule Estimated setup: ~3 mins layers Tailwind v3.4 & v4 ready code TypeScript native
lightbulb

Architectural Mindset

Sahara UI is not a monolith npm package. It acts as an open-source code registry. You select only the exact components you need, synthesize them into your repository, and mold their DOM markup and tokens directly according to your product demands.

Phase 00

1

Initialize Your Application Base

Create a fresh project scaffolding with modern React or Next.js and integrate Tailwind CSS tooling. 

pnpm create next-app@latest sahara-app --typescript --tailwind --eslint --app
2

Execute Sahara UI Init

Run the initialization utility to configure your design tokens, set up typography scale aliases, and link your component destination folder. 

pnpm dlx sahara-ui@latest init

Tip: Mirage Translucent Specular

You can activate Sahara UI's signature tactile glass effects by adding "glass": true in your components.json file. This unlocks specular reflection layers and ultra-subtle dune light diffusion.

3

Configure components.json

The components.json manifest informs the CLI of your architectural file structure, style variants, and import conventions.

data_object components.json 
{
  "$schema": "https://ui.saharadesign.dev/schema.json",
  "style": "sahara-light",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.ts",
    "css": "app/globals.css",
    "baseColor": "terracotta",
    "cssVariables": true,
    "glass": false
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui"
  }
}
4

Embed The Sahara Color Tokens

Update your CSS variables or Tailwind configuration with the warm desert mineral chromatic balance.

palette app/globals.css (CSS Variables) 
@layer base {
  :root {
    --background: #fff8f5;         /* Luminous Dune Base */
    --surface: #faf2ee;            /* Sandstone Tier 1 */
    --surface-card: #ffffff;       /* Pure Sunlit Elevation */
    --primary: #944516;            /* Terracotta Accent */
    --primary-container: #b35d2c;  /* Sunkissed Clay */
    --on-primary: #ffffff;         /* Contrast Basalt/White */
    --on-surface: #1e1b19;         /* Warm Basalt Body */
    --radius: 0.5rem;              /* Organic Soft Fillet */
  }
}
5

Add Your First Component Primitives

Generate component source directly into your codebase with one simple command: 

pnpm dlx sahara-ui@latest add button enclave-card
