## 📦 Design System Package (`@thatguycodes/design-system`)

The **ThatGuyCodes Design System** is packaged as an installable, cross-platform library supporting **Web (React / Tailwind)**, **Mobile (React Native / Expo / NativeWind)**, and **Universal Tokens**.

### Installation

#### Option 1: Via npm / yarn
```bash
# Using Yarn
yarn add @thatguycodes/design-system

# Using npm
npm install @thatguycodes/design-system

# Using pnpm
pnpm add @thatguycodes/design-system
```

#### Option 2: Via Packaged Tarball (`.tgz`)
You can download and install the standalone archive generated by `yarn pack`:
```bash
# Build tarball in the repo
cd packages/design-system && yarn pack -o thatguycodes-design-system-1.0.0.tgz

# Install in any external project
npm install ./thatguycodes-design-system-1.0.0.tgz
```

## ⚡ Development Commands

All workspace tasks are coordinated through Nx and Yarn from the root:

| Command | Action | Caching |
| :--- | :--- | :--- |
| `yarn build` | Builds all packages in parallel (`design-system`, `tokens`, `ui-native`, `web`) | Cached via Nx |
| `yarn typecheck` | Typechecks all 5 workspace projects | Cached via Nx |
| `yarn dev:web` | Starts the interactive web showcase at `http://localhost:5173/` | Live Vite HMR |
| `yarn dev:mobile` | Starts the Expo Metro bundler for iOS & Android | Live Metro |
| `yarn mobile:ios` | Launches Expo on iOS Simulator | Native simulator |
| `yarn mobile:android` | Launches Expo on Android Emulator | Native emulator |
| `yarn graph` | Visualizes monorepo dependency graph | Interactive UI |
