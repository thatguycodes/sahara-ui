## 1. Executive Summary & Brand Vision

**`thatguycodes`** is a high-authority developer media platform, interactive technical publication, and digital product storefront built on a **Sovereign, Zero-Monthly-Cost ($0.00/mo)** infrastructure. 

Unlike traditional static developer blogs that rely on expensive SaaS subscriptions ($20/mo Vercel Pro, $100/mo X API, $29/mo ConvertKit, $50/mo Zapier) or beginners' tutorials, `thatguycodes` is designed as:
1. **A Living Proof-of-Work:** Built and operated entirely on self-hosted Docker clusters, Cloudflare edge services, local/free AI inference, and 100% free syndication APIs.
2. **An Interactive Developer Workspace:** Using mature Generative UI (GenUI) and Agentic UI components (live architecture visualizers, interactive code sandboxes, dynamic article stack translators, and inline checkout widgets).
3. **A High-Margin Digital Commerce Hub:** Monetizing production-grade codebases, starter kits, automation blueprints, and productized audits with zero upfront fixed monthly overhead (using commission-only Merchant of Record infrastructure via **Polar.sh**).

## 6. Business Requirements & Operational Mandates

### BR-01: Zero-Tax Economics & Hosting Flexibility
* **BR-01.1 ($0.00 Fixed Monthly Budget Target):** The entire core platform, hosting, database, automation pipeline, email infrastructure, and analytics can operate with **$0.00/month in recurring fixed subscription costs**, with the only required expense being the annual custom domain renewal (~$10–$12/year).
* **BR-01.2 (Hosting Portability: Cloudflare vs. Vercel):** The system architecture must remain host-agnostic:
  * **Option A (The Sovereign $0/mo Stack):** Hosted on **Cloudflare Pages/Workers Free Tier** (which explicitly permits commercial e-commerce) paired with your local Mac Docker cluster or Supabase/Neon.
  * **Option B (The Managed Vercel Stack):** Hosted on **Vercel** (deploying on Vercel Hobby for development/staging, with the clear roadmap to toggle to Vercel Pro ($20/mo) once product revenue covers the subscription).
  * **Option C (100% Local Self-Hosted):** Hosted directly on your Mac laptop via Docker and Cloudflare Tunnel (`cloudflared`).

### BR-02: Content-to-Commerce Funnel with Living Repositories
* **BR-02.1 (Contextual Lead Capture):** Every technical article must include a contextual mid-post upgrade (e.g., downloadable Docker Compose file, production n8n JSON workflow, or `.cursorrules` prompt template) converting readers into newsletter subscribers.
* **BR-02.2 (Living GitHub Repository Delivery):** Digital code products must be fulfilled by automatically granting the buyer `pull` access to a **private GitHub repository** via Polar.sh. This ensures buyers receive continuous bug fixes and updates, creates high perceived value, and prevents static `.zip` distribution.

### BR-03: Omnichannel Syndication with Human-in-the-Loop (HITL) Gate
* **BR-03.1 (Single Trigger Fan-Out):** A single blog post publish event must automatically generate tailored, platform-specific content for Bluesky, LinkedIn (Post + PDF Carousel), Threads, Mastodon, Dev.to, Discord, and Telegram.
* **BR-03.2 (Mobile Approval Gate):** No automated post may be published to social platforms without prior approval. The pipeline must push previews and interactive `[Approve]`, `[Edit]`, and `[Regenerate]` buttons to a private Telegram bot / Discord channel.
* **BR-03.3 (SEO Delay Protection):** Automated cross-posting to external publishing platforms (Dev.to) must enforce a strict **24–48 hour delay** after the primary blog post goes live on `thatguycodes.com`, with `canonical_url` metadata strictly enforced to preserve Google search indexing.
